Student Performance Analysis & Prediction
📌 Project Overview
    This data science project examines the relationship between student behaviors—such as study time, attendance, and sleep patterns—and their final exam scores. 
By leveraging machine learning, the project identifies which factors are the strongest predictors of academic success and provides a recommendation engine for student improvement. 
🚀 FeaturesSynthetic 
Data Modeling: 
    Generates a dataset of 500 students with realistic noise and non-linear relationships.  
Exploratory Data Analysis (EDA):
   Includes correlation heatmaps and regression plots to visualize trends.  
Predictive Modeling: Uses a Random Forest Regressor to predict scores with high accuracy.  
Behavioral Insights: 
Quantifies the "importance" of each factor (e.g., how much 1 hour of study actually changes a grade).
📊 Key ResultsModel Accuracy: 
The Random Forest model achieved an $R^2$ score of 0.86, indicating a high level of predictive power.
Primary Driver: Study Hours remains the most significant predictor of success.  
Engagement Factor: 
Attendance acts as a critical secondary driver, often serving as a proxy for student engagement.
